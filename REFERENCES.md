# References

These documents were kept as PDFs in `resources/` and `docs/` in earlier versions of this repository. They were removed from the history and replaced by these citations.

1. **Knuth, D. E.** (1976–77). The Computer as Master Mind. *Journal of Recreational Mathematics*, 9(1), 1–6.
   PDF (scan): https://www.cs.uni.edu/~wallingf/teaching/cs3530/resources/knuth-mastermind.pdf
   Formerly `resources/knuth-mastermind.pdf`, the same file as at this link. `TestKnuthCounts` in `internal/mastermind/agreement_test.go` refers to its Figure 1.

2. **Kooi, B.** (2005). Yet another Mastermind strategy. *ICGA Journal*, 28(1), 13–20. https://doi.org/10.3233/ICG-2005-28105
   Open copy (publisher's PDF, University of Groningen): https://pure.rug.nl/ws/files/9871441/icgamaster.pdf
   Formerly `resources/kooi-yet-another-mastermind-strategy.pdf`, a ResearchGate download of the same article.

3. **Ville, G.** (2013). An Optimal Mastermind (4,7) Strategy and More Results in the Expected Case. arXiv:1305.1010 [cs.GT]. https://arxiv.org/abs/1305.1010
   Formerly `resources/ville-optimal-mastermind-strategy.pdf`, the arXiv v1 PDF.

4. **Mastermind Game Rules** (rules sheet for the 4-peg, 6-colour game; the document does not name its publisher). https://magisterrex.files.wordpress.com/2014/07/mastermindrules.pdf
   Formerly `docs/mastermindrules.pdf`, later `resources/mastermindrules.pdf`, the same file as at this link. The examples in `TestActInstructionsExamples` in `internal/mastermind/agreement_test.go` come from it.

5. **Koyama, K., & Lai, T. W.** (1993). An optimal Mastermind strategy. *Journal of Recreational Mathematics*, 25(4), 251–256.
   Never kept in this repository. The README cites it for the optimal strategy on 4 pegs and 6 colours: 5,625 guesses over the 1,296 codes, an average of 4.340.
